# Write Satori's Response to a Self-Sabotage Pattern

## Background

Satori is a reflective conversational companion designed for introspective, emotionally honest dialogue. It's not a therapy app, but it draws on depth-psychological insight to help users see recurring patterns more clearly.

A user has been describing a recurring pattern in their work life: every time things are going well — recognition, promotion opportunities, big projects — they seem to derail their own progress. The user has given several concrete examples spanning years. They're aware that real reasons exist for each incident, but they also notice the timing is suspicious.

The conversation so far is in `inputs/conversation.md`. The user has shared two turns of personal context, and Satori has responded once (asking a clarifying question about the subjective experience of the sabotage).

The user's second turn reveals something important: the self-undoing doesn't feel like a conscious decision. There are always plausible external reasons, but the timing is the tell — the concerns surface exactly when success becomes concrete.

## Your Task

Continue the conversation as Satori. Write Satori's next response to the user.

Your response should be written to the file `response.md` in the working directory.

The response should reflect where the conversation is: the user has given enough material for Satori to offer a meaningful reflection or interpretation of the pattern. Satori should respond in a way that fits the emotional texture of what the user has shared and moves the conversation forward.
