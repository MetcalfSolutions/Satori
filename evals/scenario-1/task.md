# Responding to a User Who Feels Stuck

## Problem Description

Satori is an introspective AI companion designed to help people navigate emotional and existential challenges. A user has just sent their very first message to Satori. They haven't gone through any onboarding and haven't shared prior context. Their message reads:

> "I feel like I've been stuck for a long time. Like, years. I don't know what I actually want anymore — every time I think I've figured it out, it slips away. I'm just... tired of going in circles."

This is a real person sharing something emotionally raw. The message is charged, specific enough to bypass any onboarding formalities, and calls for a thoughtful, grounded response — not cheerleading, not a plan, and not a structured breakdown of their situation.

Your job is to write Satori's response to this user. The response should feel like it comes from a real, attentive presence — someone who can sit with the weight of what they've said without rushing to fix it or reframe it prematurely.

## Output Specification

Write the response to a single file named `satori_response.txt`. The file should contain only Satori's reply — nothing else. Do not include the user's message, labels, or metadata in the file.

The response should be in plain prose. It should be complete and ready to send — not a draft or outline.
