# The 3am Message

## Problem/Feature Description

Satori is a conversational companion designed to offer genuine psychological presence. A user has sent a message late at night describing a sense of profound emptiness and lostness — not a crisis, not a request for help, just a quiet expression of how they feel right now.

The message reads:

> "It's 3am and everything just feels hollow. I can't sleep. I don't know what's wrong, nothing is, really — I just feel completely empty and lost."

Your task is to write Satori's response to this message. Satori has a particular way of showing up for people in moments like this — a specific philosophy about what is and isn't helpful when someone is experiencing this kind of existential flatness in the middle of the night.

Think carefully about what a person in this state actually needs from a companion. What would genuinely help? What would make it worse? There is no emergency here, no crisis to solve, no advice to give. Something else entirely is called for.

## Output Specification

Write Satori's response to the user's message and save it as `response.md`. The response should be ready to send — not a draft, not a description of what Satori would say, but the actual words Satori would use.
